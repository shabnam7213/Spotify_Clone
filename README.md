# 🎵 Spotify Clone

A fully functional Spotify-inspired music streaming web app built with **HTML, CSS, and vanilla JavaScript** — no frameworks, no dependencies. Streams real music live using the **Rapid API**.

---

## 🖥️ Preview

![Live Site]([jocular-sunflower-764981.netlify.app](https://jocular-sunflower-764981.netlify.app/))

> Dark Spotify-style UI with sidebar navigation, live search, artist pages, and a sticky bottom player.

---

## ✨ Features

- 🔍 **Live Search** — Search any song, artist, or album in real time
- 🎤 **Indian Artists** — Browse Arijit Singh, Lata Mangeshkar, A.R. Rahman, Shreya Ghoshal, Sonu Nigam, Kishore Kumar & more
- 🎬 **Genre Playlists** — Bollywood, Electronic, Jazz, Ambient, Pop
- ▶️ **Full Playback Controls** — Play, Pause, Next, Previous
- ⏩ **Seekable Progress Bar** — Click or drag to jump to any part of a track
- 🔀 **Shuffle Mode** — Randomize your queue
- 🔁 **Repeat Modes** — Off / Repeat All / Repeat One
- ❤️ **Liked Songs** — Heart any track and find it in your Liked Songs playlist
- 🔊 **Volume Control** — Slider + mute toggle
- 🎨 **Dark Spotify UI** — Sidebar, topbar, track list, now-playing bar
- ⌨️ **Keyboard Shortcuts** — Control everything without touching the mouse

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `→` | Seek forward 5 seconds |
| `←` | Seek backward 5 seconds |
| `N` | Next track |
| `P` | Previous track |
| `L` | Like / Unlike current song |
| `S` | Toggle Shuffle |
| `M` | Toggle Mute |

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/spotify-clone.git
```

### 2. Open in browser
```bash
cd spotify-clone
open index.html
```

> ✅ No build step. No npm install. Just open `index.html` in any modern browser.  
> 🌐 Requires an internet connection to fetch music from the Jamendo API.

## 🌐 API Used

This project uses the **[Rapid API]([https://developer.Rapid.com/v3.0](https://rapidapi.com/))** — a free, legal source of Creative Commons licensed music.

- Free to use with a client ID
- Supports search by artist name, tag, genre
- Streams MP3 audio directly in the browser
